This User Guide applies to the currently released TS10 / TSm models.

Purpose

Tool setter TS10 is designed to automatically measure the tool length and detect tool breakage on CNC milling machines. The CNC system records the coordinates when the tool touches the setter plate and uses them for automated tool length offset compensation.

The device can be used with various CNC systems: LinuxCNC, Mach3, GRBL, etc. The device is connected to the CNC system via a cable (see section Connection).

TS10 features

  1. High-precision repeatability < 0.001 mm.
  2. Hardened contact surface.
  3. Overtravel protection mechanism.
  4. Equipped with both NPN-NC and PNP-NC output types.
  5. Protection against short circuits of the output to power or ground, and reverse polarity.
  6. Compact and robust design optimized for industrial shop floors.

Connection

The tool setter is equipped with NPN-NC and PNP-NC outputs, polarity reversal protection, and protection against short circuits of the output to power and ground.
